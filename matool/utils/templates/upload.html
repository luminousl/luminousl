【脚本使用说明】
  将脚本文件解压至目标设备中，与模型文件配合使用
【注】该脚本可以在安装有tensorrt的目标设备进行使用，例如orin设备、x86设备等。
【Case 1】分析对象为onnx模型：
  python utils-device/process_onnx.py ***.onnx [trtexec args]
  python utils-device/process_onnx.py resnet18.onnx int8 fp16 plugins=./libinferplugin.so
【Case 2】分析对象为trt egine：
  python utils-device/process_trt.py ***.trt [trtexec args]
  python utils-device/process_trt.py resnet18.trt int8 fp16 plugins=./libinferplugin.so
